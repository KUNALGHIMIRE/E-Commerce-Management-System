# 🛍️ TechStore - E-Commerce App

A full-stack e-commerce application where users can browse products, add to cart, and checkout.

## 🔗 Live Demo
https://e-commerce-management-system-10.onrender.com/


## ✨ Features

- Browse products with images
- Filter by category (Electronics, Fashion)
- Search products
- Add to cart with quantity controls
- Remove items from cart
- Checkout process
- Order confirmation page

## 🛠️ Tech Stack

- **Frontend:** React, CSS3
- **Backend:** Flask (Python)
- **Database:** PostgreSQL
- **Deployment:** Render

## 🚀 Run Locally

### Prerequisites
- Node.js
- Python 3.8+
- PostgreSQL

### Steps

```bash
# Clone the repository
git clone https://github.com/KUNALGHIMIRE/E-Commerce-Management-System.git
cd E-Commerce-Management-System

# Setup Backend
cd backend
pip install -r requirements.txt
python app.py

# Setup Frontend (new terminal)
cd ..
npm install
npm run dev
